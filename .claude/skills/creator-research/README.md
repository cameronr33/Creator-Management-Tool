# Creator Research Skill

To install: open Claude Code and go to Settings > Capabilities > Skills, then
click "Import skill" and select the `HELLA - Creator Research Skill.skill`
bundle. Once installed, invoke by giving Claude a list of Instagram handles
and asking to research or vet them for a campaign.

Requires the Apify MCP connector (for `apify/instagram-scraper`), the Claude in
Chrome extension (for the reel-grid Views scrape), and `ffmpeg` on PATH for
frame extraction.
